# Support

DictateCLI is an open-source project.

- Bugs and feature requests: GitHub Issues
- Security issues: a private GitHub security advisory (see `SECURITY.md`)
- First step for any problem: `pwsh -File scripts\doctor.ps1`, which says what is wrong

When reporting a bug, include the DictateCLI version, the Claude Code version, the Windows
version, the terminal you use, what you expected and what happened. Remove secrets and
personal data from anything you paste.
